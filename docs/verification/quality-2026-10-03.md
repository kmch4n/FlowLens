# Conversation quality improvements

## Design

The frontend-design pass retains the native Qt desktop architecture and existing
palette: canvas #0D1117, chrome #131922, conversation #19212C, text #E6EDF3,
secondary text #9AA7B5, and restrained amber #D6A13D. IBM Plex Sans JP carries
interface and conversation text. Source markers use shape/text as well as color.
The primary reading column remains left-aligned, with a quieter summary column.
Repeated green healthy-state announcements and nested list borders are reduced.
Empty/error/loading states must remain understandable without relying on color.

## Public speech experiment

Source: [Japanese ReazonSpeech evaluation set](https://huggingface.co/datasets/japanese-asr/ja_asr.reazonspeech_test),
rows 0-47 retrieved through the public dataset viewer on 2026-10-03.
Audio was decoded in memory, never played or captured from a device. No private
session files were used or sent anywhere. Only public downloads used networking;
model inference used the already installed local Kotoba model on CUDA, FP16.

Reproduction: `.venv/Scripts/python.exe scripts/benchmark_public_asr.py`.
The script writes measurements to `build/reports/asr-public/beam-comparison.json`.
The dataset-viewer endpoint is not revision-pinned, so future runs may differ.

| Beam width | Normalized CER | Median decode seconds |
| --- | ---: | ---: |
| 1 | 15.76% | 0.321 |
| 3 | 15.30% | 0.351 |
| 5 | 14.83% | 0.376 |

CER uses NFKC normalization with punctuation, separators and control characters
removed, then summed character edit distance divided by summed reference length.
Applying the application's confidence filter did not change these aggregate
results. The first 24 and last 24 rows both favored beam 5 in an earlier pass.

This is a small sequential, fixed-order decoder experiment, not a benchmark of
live two-source latency, segmentation, noise rejection or this user's meetings.
The first invocation includes warm-up cost. A 0.93 percentage-point CER gain on
these clips does not establish universal best accuracy. No new model is claimed
superior. Beam 5 is used only at final decoding to limit live overhead; immutable
prefixes committed earlier are not retroactively corrected.

## Reliability

- Startup close requests stay visible until exclusive preparation completes.
- Invalid settings use defaults with a visible warning; explicit Save backs up
  corrupt bytes before replacement.
- Test fixtures cover final-pass routing and source/sample offset preservation.

A proposed 200 ms pre-VAD buffer was removed after a two-source review found
that its silent-source frontier could stall committed speech when an input
disconnects. Timing-safe onset recovery needs a separate design and live
device validation.

Physical recording/playback and full real-time meeting acceptance are not part
of this verification. Offscreen UI images do not validate native window chrome
or Windows foreground-focus behavior.
